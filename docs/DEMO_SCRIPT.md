# 1차 시연 영상 대본 — 폭우 드릴 (60~90초 화면 녹화)

목표: 심사위원이 85초 안에 "**진짜 조작을 차 값(Vehicle SDK)이 판정한다**"를 눈으로 확인하게 한다.
형식: 목업·프로토타입·화면 녹화 인정. 내레이션 없이 **자막만**으로도 이해되게 만든다.

## 1. 화면 배치

```
┌──────────────────────────────┬───────────────────┐
│  Pleos Connect 에뮬레이터     │  Virtual Console  │
│  (차 길들이기 앱, 가로)        │  Wipers / Gear /  │
│        약 70%                 │  Defroster /      │
│                              │  Exterior Lights  │
├──────────────────────────────┴───────────────────┤
│  자막 띠 (하단, 2줄 이하)                           │
└──────────────────────────────────────────────────┘
```

- 녹화 영역은 **두 창만** 잡는다(전체 화면 녹화 금지). macOS `⌘⇧5` › 선택 부분 기록.
- 출력 1920×1080, 30fps. 마우스 클릭 표시를 켜 두면 콘솔 조작이 잘 보인다.
- 콘솔 카드는 쓰는 것만 보이게 스크롤·정리: **Gear Selection, Exterior Lights Mode, Wipers, Defroster** (Steering Wheel Heat는 이번 영상에선 안 씀).

## 2. 녹화 전 준비 (리허설 1회 필수)

1. release APK(`apk/` 안의 제출 파일)를 사용자 Pleos 에뮬레이터에 설치. 제출본과 같은 APK로 찍는다.
2. 앱 데이터 지우기 → **실제 신호로** 폭우 드릴을 한 번 끝까지 리허설. 이 기록이 완료 화면의 "지난 기록"이 된다.
   시뮬레이션으로 만든 기록이 남아 있으면 지우고 다시 리허설한다(가짜 기록 비교 금지).
3. 리허설 중 확인할 것:
   - 콘솔 Wipers **Low**가 앱 판정 로그에 무엇으로 찍히는지(`INTERMITTENT_LEVEL_1` 또는 `CONTINUOUS_LEVEL_1`이어야 통과).
   - **AUTO**가 오조작 안내를 띄우는지. (콘솔에는 MIST가 없다. High는 매핑이 확인 전이라 정답으로 잡힐 수 있어 오조작 장면엔 **AUTO**를 쓴다. AUTO가 안 되면 High로 바꾸고 자막도 바꾼다.)
   - **Exterior Lights Mode**가 전조등 단계를 통과시키는지 → 장면 ③을 A안/B안 중 하나로 정한다.
   - 홈 출처 칩이 `차 신호`(시뮬레이션 아님)인지. 시뮬레이션으로 떨어지면 녹화를 멈추고 원인부터 해결(권한 등, `docs/compliance/REVIEW.md` §2).
4. 시작 상태: 콘솔 Gear **P**, Wipers **Off**, Defroster **Off**, Lights **Off(또는 Auto)**. 앱은 홈 화면.

- 시간 초과 화면은 이번 영상에서 쓰지 않는다(필요하면 2차 PT에서).

## 4. 시뮬레이션이 나오는 경우 (B 계획)

사용자 Pleos 에뮬레이터에서 녹화가 어려우면 미리보기 에뮬레이터의 **시뮬레이션 모드**로 찍을 수 있다. 그때는:

- 제목 카드 고지를 `시뮬레이션 모드 녹화 · 앱 안 시뮬레이터로 신호를 바꿉니다 · 실제 차 신호가 아닙니다`로 바꾼다.
- 출처 칩 `시뮬레이션`, 화면 상단 시뮬레이션 배지, 시뮬레이터 패널의 `시뮬레이션 — 실제 차 신호가 아닙니다` 문구가 **매 장면 보여야** 한다. 잘라 내지 않는다.
- 자막에서 "차가 판정"을 "앱이 판정(시뮬레이션 신호)"으로 바꾼다. Virtual Console을 함께 띄우지 않는다(콘솔이 신호를 보내는 것처럼 오해할 수 있음).
- 일부 장면만 시뮬레이션이면 그 장면 자막 끝에 `(시뮬레이션)`을 붙인다.

## 5. 자막 규칙

- 하단 고정, 2줄 이하, 줄당 20자 안팎. 짧은 문장, 쉬운 말. 영어 enum 이름은 화면에 보이는 값 그대로만(`AUTO`).
- 낱말 중간에서 줄을 바꾸지 않는다. "내 차", "한 단계", "기어 D" 같은 묶음은 한 줄에.
- 앱에 없는 기능을 말하지 않는다: 음성(TTS)이 구현되지 않았으면 "소리로 알려 줘요"라고 쓰지 않는다. "현대차가 올린 퀘스트"를 보여 줄 땐 화면 라벨 `제조사 안내 · 예시`가 보여야 한다.
- 숫자(통과 시간·기록 차이)는 화면에 나온 실제 값만. 자막에 미리 숫자를 적지 않는다.

## 6. 녹화 개인정보 점검표 (녹화 직전 체크)

- [ ] macOS 집중 모드(방해 금지) 켬 — 메신저·메일·캘린더 알림이 뜨지 않게
- [ ] 녹화 영역이 두 창만 덮음 — 메뉴 막대, Dock, 바탕화면 파일명, 다른 창이 안 보임
- [ ] Pleos 에뮬레이터 상태 표시줄·설정 화면·프로필에 **계정 이메일·이름이 보이지 않음** (보이면 그 화면을 거치지 않거나 자름)
- [ ] Virtual Console·에뮬레이터 창 제목에 사용자 폴더 경로(`/Users/...`)가 보이지 않음
- [ ] 터미널·Android Studio·브라우저 탭(특히 GitHub 계정, 메일) 화면에 없음
- [ ] 마이크 꺼짐(주변 소리·목소리 녹음 방지). 내레이션을 넣는다면 따로 녹음
- [ ] 완료 화면·로그에 개인 정보가 없음(앱은 이름을 받지 않음 — 확인만)
- [ ] 내보낸 영상 파일의 메타데이터(제목·작성자)에 실명이 없음. 파일명 예: `<팀명>_차길들이기_시연.mp4`
- [ ] 영상 파일은 저장소에 커밋하지 않는다(용량·개인정보). 제출 페이지 안내에 따라 업로드
- [ ] 다 찍은 뒤 처음부터 끝까지 한 번 보며 위 항목 재확인
